# Как открыть обновлённую СВЯЗКУ

1. Установите Node.js 24.
2. Распакуйте **весь архив в новую папку**; старый проект оставьте рядом.
3. Откройте терминал в папке `project`, выполните `npm start`.
4. Откройте http://127.0.0.1:3001 и зарегистрируйтесь.

Готовая сборка уже включена. Для этого запуска `npm install` не требуется.

Чтобы получить кабинет администратора после регистрации:

```bash
npm run admin -- ВАШ_EMAIL
```

Перезайдите на сайт. В бизнес-кабинете создайте организацию, добавьте вакансию, отправьте на модерацию; администратор одобряет, работодатель публикует.

**Если нужно заменить файлы в прежнем проекте:** точная таблица находится в `README.md`, раздел «Где и что заменять». Использование новой папки целиком уменьшает риск оставить старые копии.

**Для изменения исходников:** `npm ci`, затем `npm run dev`. После изменений выполните `npm run build` и `npm test`.

Вход по email работает сразу. VK ID и DaData требуют вашей настройки. Оплату и рекламные публикации оператор выполняет вне системы; сайт сохраняет заявки и их статусы. Старые облачные данные автоматически не перенесены.

Результаты проверки и ограничения: `docs/AUDIT_2026-10-10.md`. Перечень изменённых файлов: `docs/CHANGES_2026-10-10.md`.
