# OWNER INPUTS — СВЯЗКА

Данные, отсутствие которых блокирует конкретные сценарии. Не запрашивать секреты в чате.

## Блокирующие данные (для этапа B)

1. **Производственный домен** — для canonical URLs, OG previews, email links.
2. **VK ID настройки** — client_id, redirect_uri через защищённые настройки.
3. **Backend/deployment** — Timeweb credentials через защищённые настройки.
4. **DaData API key** — серверный секрет, не в VITE_*.

## Блокирующие данные (для этапа C)

5. **Тарифы подписки** — цена, период, частота поднятия. Текущие DEV-константы не являются утверждёнными.
6. **Методика рейтинга** — веса, источники доказательств, minimum sample, защита от накрутки.
7. **Финансовые правила рефералов** — DEV-константы (10% fee, 100 Emerald, 30% redemption) не утверждены.
8. **Рекламные предложения и подрядчики** — реальные проверенные предложения, цены, договорные шаблоны.
9. **Основания публикации партнёрских логотипов** — статус подтверждения для каждого партнёра.

## Блокирующие данные (для 14–17)

10. **Процесс подтверждения представителя** — выбранный метод, ответственные за проверку.
11. **Ответственные за модерацию и сопровождение** — кто проверяет вакансии, документы, подтверждения.

## Не блокируют независимые задачи

Отсутствие этих данных не останавливает этап A. Соответствующие production-сценарии отключены feature flag.
