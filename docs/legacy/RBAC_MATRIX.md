## Platform Roles

| Role | Scope | Permissions |
|------|-------|-------------|
| candidate | account | Управление своим профилем, резюме, откликами, тестами |
| business_member | account + org | Доступ к бизнес-кабинету в рамках организаций членства |
| admin | platform | Модерация вакансий, управление пользователями, партнёрами, проектами |

## Resource-level checks

- Проверка `organizationId` ресурса vs `activeOrganizationId` — на каждой операции.
- Членство в org A не даёт действий в org B.
- `status: revoked` membership закрывает доступ.
- Platform admin: модерация по явной permission policy с audit.
- Доступ к приватным сообщениям не подразумевается обычной модерацией.

## DEV vs Production

- DEV guards повышают корректность сценария, но сервер повторит проверку на B.
- Положительный DEV guard не объявляется production RBAC.
